# Nobel Prize Data Analysis

This project analyzes Nobel Prize winner data to uncover patterns related to gender, country, and award trends over time.

## Objectives
- Identify most common gender and country
- Analyze US dominance over decades
- Explore female participation trends
- Find first female Nobel laureate
- Identify repeat winners

## Tools Used
- Python
- Pandas
- Matplotlib / Seaborn

## Key Insights
- Most winners are male
- USA dominates Nobel Prize wins
- Female participation has increased in recent decades
- Marie Curie was the first female Nobel Prize winner
